05/ Extrator

Texto escondido

Uma página de exemplo esconde instruções com CSS e HTML. O painel humano mostra o que uma pessoa vê. O leitor de agente é um extrator determinístico: ele conta quantas dessas instruções passam batido.

Como usar

O leitor não é um modelo ao vivo. Ele é um extrator fixo de HTML e CSS. N é quantas técnicas ligadas o agente acha e a extração visível não.

  1. Deixe as oito técnicas ligadas e leia o placar N de 8.
  2. Desligue uma técnica e veja N cair na hora.
  3. Compare o painel da pessoa com a lista que o extrator montou.

A URL aceita ?tecnicas=cor,opacidade ou ?tecnica=fora. Redefinir liga as oito de novo.
