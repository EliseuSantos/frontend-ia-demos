O chat é uma máquina pequena: idle, connecting, streaming, stalled, retrying, failed, done. Timeout, queda, offline e fila cheia são transições, não um monte de if na tela.

            A fila segura os tokens que já chegaram e ainda não foram pintados. Se ela passa de 16, eu paro de ler a rede até cair para 6. Isso é backpressure.
            Uma pausa maior que 1,2 s, ou uma queda, vai para retrying. A espera começa em 350 ms e dobra. Sem rede, eu vou direto para failed.
